🧱 3-KATMANLI HİYERARŞİ

Neden Doğrudan Renk Değil, Semantik Alias?

Doğrudan `blue-600` veya `#2563EB` kullanmak tema değişiminde tüm kod tabanını kırar.

Token Akış Şeması

Primitive değer ham renktir. Semantic değer onun niyetini ifade eder. Component değeri ise bileşene özeldir.

/* 1. Primitive */ --primitive-indigo-500: #6366F1; /* 2. Semantic */ --brand-primary: var(--primitive-indigo-500); /* 3. Component */ --btn-primary-bg: var(--brand-primary);

Karanlık Modda Zahmetsiz Geçiş

Yalnızca semantic katman yer değiştirir. Bileşen stilleriniz (`.btn-primary`) tek bir satır dahi değişmeden koyu temaya adapte olur.

👁️ ERİŞİLEBİLİRLİK

WCAG 2.2 Kontrast Matrisi

Yüksek kontrast sadece bir tercih değil, kapsayıcı ürün tasarımının vazgeçilmezidir.

4.5:1 Metin Kontrastı

Tüm gövde metinleri arka planla en az 4.5:1 kontrast oranını karşılamak zorundadır. Başlıklar için minimum 3:1 eşiği aranır.

// Test Kontrol Kriteri test('semantic text tokens pass WCAG AAA', () => { expect(contrast(textPrimary, bgCanvas)).toBeGreaterThan(7.0); });

Focus Ring & Görsel Sınırlar

Odak göstergeleri (Focus states) hiçbir zaman `outline: none` ile gizlenmez; her iki temada da yüksek görünürlüklü halka sunulur.
