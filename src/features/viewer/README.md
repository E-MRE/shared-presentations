# Viewer entry points

Wrap viewer entry points in the shared `ToastProvider` for transient fullscreen/download feedback. Its notification viewport follows viewer-owned native fullscreen, so controls remain visible and dismissible.

`ViewerPage({ auth, service, onClose? })` is the React Router `/s/:id` adapter. Supply the current frozen `AuthState` and the real L03 service (only `getDeck` and `getAllChunks` are required). No provider, Firebase singleton, fake identity or data fallback is imported. Without `onClose`, closing replaces the route with `/`; it never follows arbitrary browser history. An integrating application may supply a callback to a known internal return route. Mount this as a dedicated route viewport instead of an overlay over another interactive route. Root/router/bootstrap integration belongs to L09.

`PresentationViewer({ id, auth, service, onClose })` is the same production viewer without router dependencies at runtime. Authentication, route and service identity key a disposable read session. Loading, visitor and unverified states never mount a session or read metadata/chunks. Logout, account/role changes, id changes and service replacement remove old content synchronously at render and discard late promises. Backend rules remain the authorization authority; the UI additionally blocks nonpublished decks belonging to others. Metadata count/manifest/version/aggregate bounds are checked before a chunk read. Existing bounded `reconstructPresentation` handles both formats; actual decoded byte length must also match unpacked metadata.

The route is a normal `main`, not an ARIA modal or fixed background overlay. HTML uses `srcdoc`, `sandbox="allow-scripts"`, `allow="fullscreen"` and a deck-specific title. No frame URL/helper/slide bridge is created. Uploaded HTML never enters the parent DOM. Controls request fullscreen on the entire viewer. F/Esc act only on focused app chrome, excluding editable controls and frame focus; visible controls work independently. Escape exits viewer-owned native fullscreen first. Fullscreen events/listeners and ownership are cleaned up on leave. Browser-native Escape handling can exit fullscreen without dispatching a page key event; its fullscreenchange still updates the button.

PPTX metadata is shown without chunk reads or converters. Download reconstructs identity bytes only after a click, blocks overlapping requests, rejects stale completions, uses the PPTX MIME and a sanitized basename. Download object URLs have a 30-second lease, including after unmount, so Chromium can consume activated downloads; each timer revokes its URL and holds no DOM/React state. Cover JPEG/WebP URLs are revoked on replacement/unmount. Invalid covers use the title fallback. Resource links are validated again while rendering, accepting only absolute HTTPS URLs without credentials, with noopener/noreferrer.

All product copy is Turkish. Scoped CSS uses approved graphite/white/blue primitive tokens and Plus Jakarta Sans/JetBrains Mono, forcing dark route semantics in either application theme. Bilgi uses native buttons and expanded/controls semantics; loading/errors are announced, touch targets are at least 44px, long tokens wrap and reduced motion disables transitions. At narrow widths the metadata panel becomes a scrollable lower panel, while close and fullscreen stay visible.
